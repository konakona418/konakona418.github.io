夏天的终结

2026-09-15杂谈 · 生活约 7 分钟

马塞尔·杜尚和他的《泉》

我上大学以后写的第一个项目是什么来着？

那个时候 LLM 还远没有现在发达，我感觉当时 ChatGPT 都有点笨笨的感觉，充其量只能算是个有问必答的助理；没两年 LLM 就已经发展成了这个样子，属实令人讶异，现在我都不需要写代码，只用给 GPT 派任务就行了。有时候自作聪明干预它，反而会整出事情来。当时刚进竞赛基地，那时候人型组还有点钱，虽然是流放厕所旁边，每天都闻那个臭不可闻的味道，时不时就飘来缕缕暗香。但是毕竟经费到底是有的，马桶味就忍了吧；这两年倒是搬到宽敞明亮干净整洁的办公室里面了，和团委的为人民服务的诸公位列一栋楼里，但是大课题组发的钱却反而变少了，不知道是不是所有人只要进了那栋楼，就也要响应清正廉洁大公无私，时刻准备为组织利益牺牲个人利益的号召了。宇树机器人看的我实在心痒痒，要是有钱，我宁愿去坐厕所旁边呀！当然，不用呆在厕所旁边也有钱就最好了。

总之那个时候确实还是在厕所旁边。

WebAssembly 技术在 FLV 视频即时转封装中的应用

WebAssembly 在 FLV 转 fMP4 中具有潜在的优势，主要体现在性能提升、跨平台兼容性、流媒体处理效率、轻量级部署和开发者友好等方面……

その時 我在学 Rust，就琢磨着怎么写个项目练手。然后不知道哪根筋搭错了，看到 flv.js 就想要写个 flv.rs 用 WASM 跑在浏览器里面。于是每天就坐在基地里面写代码，从傍晚写到凌晨，写了三周居然写出来了。当然客观来讲这个项目写的是非常拉胯的。最早我不知道 WASM 的模型不允许多线程，于是开了好几个线程互相 mpsc::channel 发送消息，最后迁移时不得不大重构；不会用 serde，于是解析和构造全部手写；没有任何零拷贝也就算了，而且还 .clone() 满天飞。而且生命周期也乱七八糟的。

由于浏览器的安全性限制，Rust 标准库中的线程实现无法直接应用于 WebAssembly。因此，本项目选择放弃多线程功能，尽管在某些场景下多线程可能更为高效。然而，考虑到与本实验项目性质类似的 flv.js 默认采用单线程，且其多线程模式并不稳定，可以认为这种潜在的性能损失对程序的整体效率影响较小。在牺牲程序稳定性的前提下追求性能提升并不具有成本效益。因此，对于此方面的优化可暂缓讨论。

但是到底是能跑起来了，虽然第一次跑起来还有一个诡异的画面闪回问题，排查了一周多才排查出来 帧的 decode time 和 presentation time 是不一样的，而我默认把两者的 offset 置为了 0。

总的来说虽然中途坐牢完了，但是最后出来结果的时候是真给我高兴坏了，反复换各种视频播放，令人感叹。

另外软院新生研讨课论文是拿这个项目水的。那时候学院还没有要求人人会 YOLO 且人人 必须做 YOLO。

心的规律与自大狂

我写完这个项目我感觉我牛逼到爆炸了！试问哪个大一学生做得到？我马上就能找到音视频处理相关工作了！

后来我才知道在国内音视频处理并不好找工作。得知这个不幸的消息后，我毅然转战游戏引擎开发，随后发现引擎开发也不好找工作。

仿佛看到原子弹爆炸眩晕瘫坐

现在很多人给我一种感觉，就是他们有一种 nostalgia out of nowhere。往极端了讲就是“LLM你把多少人的生活都毁了”，然后怀念那个纯手写的时候。然而事实就是在LLM之前程序员也是从CSDN（国内）或者StackOverflow（国外）上面抄东西，现在无非把这个过程 delegate 给了LLM而已。

前段时间看到一个搞 CUDA 算子的人写的文章也是通篇这种态度。但我看来，甚至算子优化这个工作也是事实上的简单重复工作，本身就是写一个 kernel 然后不停跑 profile，根据 profile 里面显示出的 hotspot 针对性优化 kernel 然后一直 loop 就行了。不过好在他不是一种骂骂咧咧的誓与旧时代共存亡的态度。我觉得，现在这个简单重复工作时间省下来了，这些高智商人才就完全可以去做科研或者随便什么事情了呀。

至于某些人担心的什么赛博朋克2077未来……openweb（开放互联网）早都死球了，中心化网络决定了 open 注定只能是 Stallman 之类几个计算机老左的幻想（尽管 GNU 基金会在某种程度上是成功的），我不认为因为一个全新领域出现或不出现垄断就会把我们导向一种dystopian或者共产主义的未来。Andrew Kelley 非常担心这件事情，他说 If you cannot control the source code you can control nothing；当然这里的 source code 也可以引申为 weights 之类的。像我一点不担心这件事情，我没有他那样的弥赛亚情结。要是真的出垄断巨企了，我立刻自杀。

所以我现在其实也不太理解那些怀念所谓纯手写时代的人。不是因为我觉得 LLM 有多么牛逼，而是因为我确确实实切身经历过那个时代。那时候也没什么莫名其妙的诗意（就好像有些作家美化所谓乡土生活而拒斥对于都市的描写一般），更多的时候就是搜半天 StackOverflow，复制一段不知道谁写的代码，然后发现根本跑不起来，再坐在那里 debug 半天。只不过那时候至少想做什么，就去做什么。

现在反而想不到自己想要做什么了。

西安森林

至少坐在厕所旁边写代码的时候，我还是相信，只要投入足够多时间和精力，我便能文能武，无所不能了。当时总是跟别人说，我肯定是热爱着计算机科学的，总是对别人说，计算机科学给我带来无数惊奇。但是现在想来大概就是立牌坊然后自我标榜罢了。与其说是热爱计算机科学，倒不如说是没什么别的东西可以热爱了，于是就像抱着救命稻草一样死死抓着这个东西不放。

前段时间有个同学跟我吐槽说感到十分迷茫，不知道未来要干什么。难道我就不迷茫吗，完全不知道以后要做什么。但我进校的时候就已经知道会这样了，在其他人都还非常开心充满希望的时候。最后总会变得迷茫而无所适从，说到底又是什么支撑我一直走下去的呢。倒不如说是沿着“学计算机”这个不知何时强行诱导出来的 trajectory 走下去成为了目的本身了吧。说什么不要否定掉之前的自己做的工作，不要因为现在的不如意就否定掉之前的快乐，不要否定掉计算机行业，不要变得 cynical，don’t take the black pill（Andrew Kelley 语），但说到底只有 andrewk 这种水平的人才能站着说这种话还不自觉腰疼吧，其他卡在中间上不去下不来的人怎么办就只有天知道了。sorry（as sorry in Lean4）

有个同学跟我说不喜欢《漂流少年》的结局。但说实话我还挺喜欢的，我认为这个结局在一定程度上构成了对于我们一群人，乃至一代人即将经历或者正在经历的创伤的某种隐喻，所以从这个角度上来讲这个作品是反映了时代精神的。但是至少长良自己选择了回归“惨淡的”现实世界，而有些人甚至没得选。不论主动选择还是被动接受，“回去”本身并不代表事情的结束。某种意义上它甚至是事情的开始。回去以后没有人告诉你应该做什么，不该做什么，没有一个固定的无可辩驳的绝对的目标在了。我感觉我有点不知道怎么编了，所以闲话休题——

——夏天就要结束了。奇幻的冒险就要结束了。
